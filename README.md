## 🔧 What I'm Building
 
**[ASIE — Automated Sentiment Intelligence Engine](https://github.com/sharjeel6392/asie)**
A production-grade NLP MLOps system covering the full ML lifecycle:
- Reproducible training pipelines with **MLflow** and **DVC**
- Immutable model promotion and dual-model **shadow deployment**
- Kubernetes-native serving on **Amazon EKS** via Helm — HPA, PodDisruptionBudgets, zero-downtime rolling updates
- **4-signal drift detection engine** — input distribution, label distribution, confidence shift, shadow disagreement — without ground truth labels
- Full alerting pipeline: **Prometheus → Alertmanager → structured webhook events**
- IaC with **Terraform**: VPC, private subnets, NAT Gateway, bastion host, IRSA
*Currently extending with Airflow-orchestrated retraining DAGs and ArgoCD GitOps rollouts.*
